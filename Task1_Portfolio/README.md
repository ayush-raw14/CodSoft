# Task-1 Personal Portfolio

This is a modern and professional personal portfolio website built using **HTML, CSS & JavaScript**.
It showcases my skills, projects, and provides contact information for potential opportunities.

---

# Features
- Modern Dark Theme with Gradient Accents
- Fully Responsive Design (Mobile-Friendly)
- Smooth Scroll Navigation
- Interactive Hover Effects
- Project Showcase Section
- Downloadable Resume
- Contact Information Display

---

# Technologies Used

- **HTML5**   - Building the structure and semantic layout of the portfolio.
- **CSS3**    - For modern styling, animations, and responsive design.
- **Font Awesome 7.0.1** - For icons and visual elements.
- **Google Fonts (Poppins)** - For clean and modern typography.

---

# Sections Included

1. **Hero Section** - Introduction with headshot image and quick navigation links
2. **Skills Section** - Display of technical skills with logos (HTML, CSS, JS, Python, C++)
3. **Projects Section** - Showcase of 3 sample projects with images and descriptions
4. **Contact Section** - Email, phone, and LinkedIn contact cards
5. **Resume Section** - Download button for PDF resume

---

# How To Run
1. Clone or Download this Repository.
2. Navigate to the folder "CodSoft/Task1_Portfolio".
3. Run the **index.html** file in any modern Web Browser.
4. Ensure the **images** folder and **cstyles.css** file are in the same directory.
