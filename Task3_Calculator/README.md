# Task-3 Calculator

This is a simple and modern calculator using **HTML, CSS & JavaScript**.
It can perform basic arithmetic operations such as, Addition, Subtraction, Division and Multiplication.

---

# Features
- Clean and Modern Design
- Supports Keyboard and Button Input
- Performs Basic Arithmetic Operations
- Error Handling and Invalid Inputs

---

# Technologies Used

- **HTML5**   - Building the basic skeleton for the calculator.
- **CSS3**    - For styling and design of the calculator.
- **JS(ES6)** - For functionality and logic.

---

# How To Run
1. Clone or Download this Repository.
2. Navigate to the folder "CodSoft/Task3_Calculator".
3. Run the **body.html** file in any modern Web Browser.
