# Task-2 E-Commerce Landing Page

This is a modern and premium e-commerce landing page for **SNS Fashion** built using **HTML, CSS & JavaScript with GSAP animations**.
It showcases seasonal clothing collections with smooth scroll animations and an elegant user interface.

---

# Features
- Modern Gradient Design with Seasonal Themes
- Smooth GSAP Scroll Animations
- Fully Responsive Layout
- Three Seasonal Collections (Summer, Winter, Autumn)
- Product Cards with Hover Effects
- Customer Testimonials Section
- Statistics Counter Display
- Fixed Navigation Bar with Blur Effect
- Mobile-Friendly Navigation

---

# Technologies Used

- **HTML5**   - Building the structure and semantic layout of the landing page.
- **CSS3**    - For modern styling, gradients, animations, and responsive design.
- **JavaScript (ES6)** - For interactive functionality and scroll effects.
- **GSAP 3.12.5** - For smooth scroll-triggered animations and transitions.
- **ScrollTrigger Plugin** - For scroll-based animation triggers.

---

# Sections Included

1. **Hero Section** - Eye-catching hero banner with gradient background and call-to-action
2. **Statistics Section** - Display of key business metrics (10K+ customers, 500+ styles)
3. **Summer Collection** - 4 product cards with summer clothing items
4. **Winter Collection** - 4 product cards with winter clothing items
5. **Autumn Collection** - 4 product cards with autumn clothing items
6. **Features Section** - Highlights of premium quality, free shipping, and easy returns
7. **Testimonials** - Customer reviews and feedback
8. **Final CTA** - Call-to-action for shopping
9. **Footer** - Contact information and quick links

---

# How To Run
1. Clone or Download this Repository.
2. Navigate to the folder "CodSoft/Task2_LandingPage".
3. Run the **index.html** file in any modern Web Browser.
4. Ensure **style.css** and **script.js** are in the same directory.
5. Internet connection required for GSAP CDN and product images.
